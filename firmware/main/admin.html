Wi-Fi networks

The board joins the strongest saved network in range by itself. The IMU-Lab network stays on either way. Looking for networks briefly silences IMU-Lab, so the board only does it on its own while nobody is connected to IMU-Lab; otherwise use the button below. When it joins a network on another channel, IMU-Lab moves to that channel too, so devices on IMU-Lab drop off for a few seconds and reconnect.
